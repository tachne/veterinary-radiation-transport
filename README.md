# Veterinary Radiation Transport Lab v0.2.1

「β線の飛程」→ **「Sr-90 / Y-90 放射平衡」** で、核種別の連続スペクトルから電子を抽選し、7種類の均一な試料で経路長とエネルギー損失を比較できます。線源データとESTAR表は同梱しており、実行時の外部通信は不要です。γ線画面と従来の単色電子はv0.1.1のままです。

## 起動

Python 3.13で、このフォルダから実行します。初回のセットアップにはインターネット接続が必要です。

```sh
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8514
```

このPCのブラウザで [ローカルアプリを開く](http://127.0.0.1:8514/)。このPCでは専用環境を作成済みです。次回からはフォルダ内で `.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8514` を実行します。終了は Ctrl+C。

## 放射平衡β線を試す

1. 「β線の飛程」で平衡線源を選び、左欄で試料を **水・0.2 cm** にします。側面の設定欄が図に重なる場合は、左上の矢印で閉じられます。β粒子数10,000、β乱数シード42のとき、Sr-90は4,953個、Y-90は5,047個です。
2. スペクトルの実線は各核種、破線は1：1の混合です。「抽選した全粒子」の凡例で、同じ軸に標本を重ねられます。初期エネルギー・経路長・残存エネルギーは番号を指定して20、50、100個ずつ確認できます。
3. 試料や厚さを変えると、同じ初期エネルギーの粒子が別の物質を通る場合を比較できます。「新しい乱数でβ線を再照射」だけがβシードを新しく生成します。手入力で42に戻すと同じ標本に戻ります。シード・表示範囲はセッション別です。
4. 核種別の集計、表示中の粒子、全粒子を別々のCSVに保存できます。粒子別CSVには物質・厚さ・密度、阻止能、適用範囲、線源とESTARの出典、シードとモデル版を記録します。空欄（計算値なし）と0（計算で確定）は別です。低エネルギー域の扱いは[物理モデル](MODEL.md)を参照してください。

**v0.2.1の飛跡図**では、青い丸はCSDA経路を使い切った位置（残存0 MeV）、緑の右矢印は試料出口で描画を打ち切った位置です。横軸は経路長を直線上に配置した教育用の尺度です。矢印は実際の電子透過を保証しません。右欄の灰色の×は距離を示しません。

上記の条件で開始粒子番号を **20** にすると、20〜39番の中で3つの記号を比較できます。**26番**は初期10 keV未満で飛程を算出できず、×だけです。**2,335番**は飛程が試料厚より長いため出口に矢印が付きますが、残存値は0超〜10 keV未満で数表外のため×も付きます。どちらも残存値を0で埋めません。β線の計算モデルとCSVはv0.2.0と同じです。

## 操作

左側で7種類から試料を選び、厚さとそれぞれの入射エネルギーを設定します。数値欄は直接入力して Enter で確定できます。空気など距離の長い試料にも対応するため、厚さの単位は全タブで cm に統一しました。

| タブ | 表示と操作 |
|---|---|
| γ線の相互作用 | 開始番号と表示本数（20・50・100本、任意の1〜100本）を設定し、前後のページを移動できます。HVL通過数と出口透過数を、全光子と表示中の光子で比較します。 |
| β線の飛程 | 線源を「単色電子」または「Sr-90 / Y-90 放射平衡」から選択。左の電子エネルギー入力は単色線源のみで使用します。 |
| γ線・β線比較 | 従来どおり、同じ試料について一次光子の透過確率と**単色電子**の経路長を並べます。平衡線源の核種比較は「β線の飛程」のC欄です。 |
| 物質特性 | 現在のエネルギーにおける係数・飛程、7物質の代表密度・元素質量分率・出典を表示します。 |

「▶ 飛跡を再生」は選択範囲の経路をブラウザで再生します。ページ移動は計算済み標本の別の番号を表示します。「新しい乱数で再照射」は現在と異なるシードを生成して全光子を再計算します。シード欄に元の値を入力すると、同じ物理条件で同じ標本を再現できます。

「光子ごとのCSV出力」を開くと、表示範囲と全光子を個別に保存できます。光子番号は全標本の通し番号です。`first_interaction_depth_cm` は試料内での初回相互作用深度（透過時は空欄）、`sampled_free_path_cm` は均一物質が続くと仮定して生成した自由行程、`track_end_cm` は試料内の経路の終点です。`passed_hvl_in_sample` と `transmitted_exit` は1が通過、0が非通過です。HVLが試料外のときHVL判定は空欄になります。

各タブの下端には従来の集計CSVがあります。透過率は画面で%、結果CSVで0〜1の割合です。CSVは単位を含む列名、モデル版、試料条件、取得日、出典を含み、Excelで開けるUTF-8 BOM付きです。入力と標本はセッションごとに処理し、学生の設定や操作履歴を書き込みません。
